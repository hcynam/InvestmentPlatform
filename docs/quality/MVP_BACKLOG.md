# Backlog پس از MVP

- راهنمای حرفه‌ای پارامترها و معماری baseline/target/source برای KPIها.
- مدل چندمحصولی، چرخه هر خط، پروفایل ماهانه/فصلی و editor تفصیلی ramp-up.
- workflow کامل مجوز، استاندارد، مالک/موعد/ریسک باقیمانده و HSE/لجستیک/فناوری.
- پایگاه benchmark و recommendation صنعت‌محور فقط پس از تثبیت داده و source governance.

## بهبودهای پس از تثبیت مدیریت سناریو

- کتابخانه الگوهای خوش‌بینانه، بدبینانه، شوک ارزی، تورمی و تأخیر فقط پس از تعریف ضریب، منبع، مدت، قاعده ترکیب و نسخه‌بندی.
- مدل احتمالاتی سناریو شامل probability، risk weight، Expected NPV و رتبه‌بندی وزنی فقط پس از تصویب قرارداد مدل‌سازی.
- جست‌وجو، مرتب‌سازی، آرشیو، pinning پیشرفته، توضیح خودکار شوک بی‌اثر، نمودار delta اختیاری، snapshot تاریخی مبنا و منحنی شوک زمان‌مند.
